# Kira-CEO Brooklyn

Frontend estático do Kira-CEO Brooklyn hospedado no GitHub Pages. O backend permanece no Supabase (Auth, PostgreSQL, RLS e Edge Functions).

## Publicação

O workflow `.github/workflows/pages.yml` publica a branch `main` no GitHub Pages.

## Segurança

Este repositório não deve conter `service_role`, senha de banco, JWT secret ou outras credenciais privadas.
